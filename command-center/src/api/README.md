# src/api

Клиент API фабрики. Сейчас здесь только `client.ts` — `apiUrl` / `apiGet` и временная
ручка `getHealth`. В CC-0004 сюда ляжут типы и функции, сгенерированные из
`../api/openapi.json` (корень фабрики); руками их не писать.

API всегда на том же origin, что и приложение (`<base>api/…`). В dev-режиме Vite
проксирует `/api` на адрес из `CC_API_URL`.
